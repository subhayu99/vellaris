# Vellaris

> Files only the people you choose can read.

**Vellaris** is open-source, end-to-end encrypted document sharing you
self-host. Your server stores ciphertext. Your laptop holds the keys. Your
colleagues just get the file.

This documentation site is a Phase 0 placeholder. Real content lands in
Phase 5:

- Quickstart (CLI in 60 seconds, server in 5 minutes via `docker run`)
- Security model — what's protected, what isn't
- CLI reference, Python SDK reference, OpenAPI spec
- Deployment guide (Docker Compose, Kubernetes, fly.io / Railway)
- "Build your own client" guide (on-wire format spec)

## Install

```bash
pip install vellaris
```
